# Go Present Tool

This is a fork of the `present` tool from
[`golang.org/x/tools/present`](https://pkg.go.dev/golang.org/x/tools/present).

I made this a rather hard fork because I don't expect changes from upstream.
I would be honored to get changes merged back, but I don't expect that to happen.

The main differences are:

- Support for switching between dark and light mode.
- Showing bullet points one by one when pressing the space bar.
  You can also use the up and down keys to switch between slides quickly.
- Using the available space better by minimizing margins and padding.

Of course I didn't change the license.
